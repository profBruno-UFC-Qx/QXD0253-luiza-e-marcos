# Telas implementadas

Esta pasta deve conter as quatro telas referente as entrega dos protótipos de tela.

Os prototipos estão disponiveis em `frontend/` nos arquivos:

- `login.html`
- `cadastro.html`
- `dashboard.html`
- `catalogo.html`

## Exemplo

- **Tela de login**
  - Formulário de autenticação com campos de email e senha
  - Permite ao usuário acessar a área restrita da plataforma
- **Tela de cadastro de usuarios**
  - Formulário de criação de conta com nome, email, senha e confirmação de senha
  - Serve para novos alunos e professores se restrarem no sistema
- **Tela de principal apos o login**
  - Dashboard do usuário autenticado
  - Exibe boas-vindas, visão geral de jogos e progresso
  - Inclui navegação interna e botão de logout
- ## **Tela catalogo de jogos**
  - Lista de jogos educativos disponíveis
  - Cada cartão apresenta título, categoria e botão “Jogar”
  - Representa a tela extra obrigatória da entrega

## Observações

- Estas telas são protótipos em HTML/CSS, com foco no fluxo de navegação
- O backend ainda não está integrado; o objetivo atual é mostrar a estrutura visual e funcional inicial que foi pedida
- Deixamos os prints das telas aqui apenas para apresentação
